# AI Use Case Atlas

A local/offline knowledge base for learning AI through real-world use cases.

## What it contains

- 64 AI/ML use cases
- 49 core AI concepts
- Search and filters by domain, task, and learning paradigm
- End-to-end pipelines
- Why each model/concept is used
- Metrics and interview questions

## Run locally

No installation is required.

1. Clone or download this repository.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.

## Topics covered

- Machine Learning
- Supervised / Unsupervised / Self-supervised Learning
- Regression / Classification / Clustering
- Neural Networks / Deep Learning
- CNN / Transformer / Attention
- Backpropagation / Gradient / Optimizers
- Computer Vision
- NLP / LLM / RAG
- Recommendation / Ranking
- Time Series / Anomaly Detection
- Reinforcement Learning
- Generative AI / Multimodal AI

## Project goal

Build a growing AI Use Case Knowledge Base that connects:

`Use case -> problem -> data -> learning paradigm -> task -> model -> training -> metrics -> inference -> interview reasoning`
